1. Deskripsi Praktikum
Praktikum ini dilakukan untuk mempelajari cara menghubungkan PHP dengan database MySQL menggunakan XAMPP dan phpMyAdmin.
Pada praktikum ini dibuat aplikasi sederhana untuk mengelola data barang menggunakan operasi CRUD (Create, Read, Update, Delete).
<img width="437" height="297" alt="Screenshot 2026-11-22 151949" src="https://github.com/user-attachments/assets/fe8ce2c3-426e-4952-aef1-1e73d85dd825" />

2. Tujuan Praktikum
Memahami koneksi PHP dengan database MySQL.
Membuat database dan tabel menggunakan phpMyAdmin.
Menampilkan data dari database.
Menambahkan data barang.
Mengubah data barang.
Menghapus data barang.
Menampilkan gambar barang.

4. Fitur Aplikasi
Aplikasi ini memiliki beberapa fitur, yaitu:
Read: Menampilkan daftar barang dari database.
Create: Menambahkan data barang baru.
Update: Mengubah data barang yang sudah tersimpan.
Delete: Menghapus data barang dari database.
Gambar Barang: Menyimpan file gambar produk di folder gambar dan menampilkan gambar pada halaman aplikasi.

Buat database dengan nama latihan1 di phpMyAdmin.
Buat tabel data_barang beserta kolom-kolomnya.
Simpan folder project di dalam folder htdocs.
Buka browser.
Masukkan alamat berikut:
